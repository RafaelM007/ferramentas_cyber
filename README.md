## 💻 Useful Linux Commands

| Comando | Finalidade |
|---|---|
| `file arquivo` | Identifica o tipo real do arquivo. |
| `strings arquivo` | Extrai textos legíveis. |
| `binwalk arquivo` | Identifica dados e arquivos embutidos. |
| `exiftool arquivo` | Exibe metadados. |
| `xxd arquivo` | Exibe conteúdo hexadecimal. |
| `hexdump -C arquivo` | Visualiza bytes em hexadecimal e ASCII. |
| `grep -r "flag" .` | Procura textos em arquivos e diretórios. |
| `find . -type f` | Lista arquivos recursivamente. |
| `nc HOST PORT` | Estabelece conexão TCP com um serviço. |
| `strings arquivo \| grep -i flag` | Procura possíveis flags em strings. |
